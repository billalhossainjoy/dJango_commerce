# Workspace agent instructions

## Grill Me

- Treat the installed `grill-me` skill as the default discovery workflow in this workspace.
- Always invoke it when the user asks to explore, externalize, interview, grill, stress-test, or pressure-test a plan, process, decision, or mental model.
- Follow the skill's own scope boundaries: do not invoke it for a simple factual request, a single quick capture, or when the user directly requests implementation or a finished deliverable.
- During a grill session, save every answer to the workspace capture file before asking the next question, as required by the skill.
